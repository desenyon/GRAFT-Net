# GRAFT-Net v0.1.0 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a research-grade PyTorch repository for GRAFT-Net v0.1.0 with predictive attention, gradient-routed experts, latent topology learning, baselines, three benchmark families, ablations, visualization tooling, and separate local/scale configs.

**Architecture:** The repository will use a modular `src/graft_net` package with reusable model modules, a shared training and evaluation harness, Hydra-based configuration, and benchmark adapters for sequence classification, time-series forecasting, and an experimental graph prediction track. Every novel module will be implemented behind explicit ablation switches and verified through strict test-first development.

**Tech Stack:** Python 3.11, PyTorch, Hydra, pytest, ruff, mypy, matplotlib, seaborn, networkx, torchmetrics, einops
